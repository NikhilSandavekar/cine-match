# Cine-Match

A mobile-first, group movie, series, and anime recommendation app. Friends create or join a room, tune global/India, category, and genre filters, then swipe through spoiler-free picks with India streaming availability and trailer playback.

## Current experience

- Mobile-first swipe flow
- Room creation and joining interface
- Global and India catalogue filters
- Movies, series, anime, and every major genre
- YouTube trailer pane
- Hindi / English interface switch
- Installable web-app metadata

## Planned next product slice

- Account-backed watch history and liked/disliked picks
- Live shared-room syncing
- Optional social login
- Privacy-first data controls
